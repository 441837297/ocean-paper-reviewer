# Source basis and provenance

This file documents where the review rules came from. It is not required for every review.

## Primary lecture sources supplied by the user

1. `中科院长光所写作1_原文.docx`
   - overall principles: focus, logic, clarity;
   - manuscript structure and section responsibilities;
   - title and abstract guidance;
   - paragraph/transition/tense/vocabulary advice;
   - visual clarity and common overselling warnings.

2. `中科院长光所写作2_原文.docx`
   - Introduction purpose and standard functional structure;
   - Results organization and figure-led storytelling;
   - Discussion explanation, limitations, and forward implications;
   - Methods reproducibility-facing detail;
   - references/acknowledgements;
   - editorial topics such as innovation self-assessment, reviewer recommendation, and appeals.

The speech-to-text transcript contains obvious recognition errors, including section names such as Results or Methods being misrecognized. When transcript wording conflicts with the embedded lecture slide, the slide is treated as the higher-confidence source.

## Migrated OPW source

The former OPW `references/review/tutor-review-checklist.md` contributed:

- Abstract information density and quantitative interpretability;
- four-level Introduction funnel;
- literature-role checks;
- Results separation of observation, attribution, and speculation;
- Discussion closure and dimensioned literature comparison;
- limitation structure;
- clause-level citation alignment;
- claim-strength boundaries;
- manuscript-wide number/term consistency;
- Introduction-Discussion closure map.

These checks belong in the whole-manuscript reviewer and should not be duplicated in OPW after migration. OPW should retain its own evidence constitution, Feedback, Revision Brief, Prose, and Verify workflows.

## Design additions made for reusable skill behavior

The following elements are workflow design, not direct quotations from the lecture:

- severity classes (`BLOCKER`, `MAJOR`, `MINOR`, `HEURISTIC`);
- issue IDs and repair-unit output format;
- `Full Preflight`, `Focused Recheck`, and `Section Audit` modes;
- separate issue owners (`USER_OR_JOURNAL`, `OPW`, `NATURE_STORY`, `REVIEWER_SELF`) and recommended routes (`OPW_STRATEGY`, `OPW_PROSE_VERIFY`, `NATURE_STORY`, `NONE`);
- confirmation-before-routing rule under OPW control;
- no single numeric manuscript score;
- `CLEAR_WITHIN_SCOPE` as an internal review state.

These additions make the source guidance executable without pretending that every lecture preference is a universal scientific norm.

## Deliberately excluded from the core reviewer

The lectures' manuscript-relevant guidance is represented in the core checks or soft heuristics, not copied as universal requirements. Reviewer recommendation strategy and post-rejection appeals are submission-management topics, so they are not part of the core workflow.

Innovation/priority language remains in scope only as a manuscript claim-strength issue. A real novelty determination should be routed to Nature Story or a dedicated literature audit.
